# Direct Mapped Cache (Verilog)

📌 **Описание:**
Данный проект реализует модель простого кэша с прямым отображением (Direct Mapped Cache) на языке Verilog. Основная задача — демонстрация базовой архитектуры кэша: разбиение адреса на индекс и тег, механизм hit/miss, хранение данных и проверка через тестбенч.

---

## 💡 Функционал

- 🛠 **4 строки кэша** (размер настраиваемый).
- 🏷 Разделение адреса:
  - Младшие биты — **index** (номер строки).
  - Старшие биты — **tag** (идентификатор блока).
- ✅ **Valid-биты** для проверки актуальности данных.
- 👁 **Hit/miss логика**:
  - Сравнение тега и valid-бита для определения попадания (hit) или промаха (miss).
- 📝 **Тестбенч** с 5 сценариями:
  1. Чтение из пустого кэша (ожидаем miss).
  2. Запись данных в кэш.
  3. Чтение после записи (hit и проверка данных).
  4. Проверка промаха по другому тегу.
  5. Проверка сброса.
